رفع الترتيب، باك لينك، وتقارير.

## التشغيل (5 دقائق)

1. ثبّت إضافة **Claude** من Chrome Web Store (الناشر: Anthropic) وسجّل الدخول.
2. سجّل الدخول بنفسك في تبويبات: لوحة ووردبريس `/wp-admin`، Ahrefs، Semrush،
   Google Search Console، Google Analytics، Gmail.
3. افتح `ALL_AGENTS.md` بالمفكرة ← Ctrl+A ← Ctrl+C.
4. افتح لوحة Claude في Chrome ← الصق ← أرسل ← اكتب **ابدأ**.
5. أجب عن 5 أسئلة قصيرة (رابط الموقع، اللغة والدول، اسم الكاتب، المنافسين اختياري، تأكيد الدخول).

بعدها يعمل وحده: يفحص الموقع ويصلح الأخطاء، يبني خريطة الكلمات، ثم يكتب وينشر يومياً.

**كل يوم:** الصق `ALL_AGENTS.md` + آخر PROJECT STATE واكتب **الخطة اليومية**.

## ماذا سيطلب منك فقط

- تسجيل الدخول، الكابتشا، والتحقق بخطوتين (لا يحلّها ولا يتجاوزها).
- الموافقة على: إرسال الإيميلات، حذف أي شيء، تعديل ملفات PHP، تغيير الروابط الدائمة أو الاستضافة، أي دفع.
- كل ما عدا ذلك (البحث، الكتابة، النشر، السيو، تعديلات CSS، الروابط الداخلية) يقوم به وحده.

## قواعد الجودة المدمجة (لحماية موقعك من عقوبات Google)

- مقالات أصلية ودقيقة ومفيدة فقط، مع مصادر؛ لا نسخ ولا إعادة صياغة لمقالات الآخرين.
- وتيرة **2–5 مقالات قوية يومياً** + الأخبار العاجلة — لا إنتاج جماعي لمقالات ضعيفة
  (Google يعاقب "المحتوى المنتج بكميات للتلاعب").
- نسخة احتياطية قبل أي تعديل تقني، وتعديل القالب عبر قالب فرعي أو CSS إضافي فقط.
- باك لينك نظيف فقط: لا شراء روابط، لا سبام، لا حسابات وهمية.

## توقعات واقعية

الوكلاء يطبّقون أفضل الممارسات بانتظام، وهذا هو الطريق الصحيح للوصول لترتيب عالٍ وزيارات كبيرة،
لكن **لا أحد يستطيع ضمان** المركز الأول أو ملايين الزيارات. عادة تظهر النتائج الأولى خلال
2–3 أشهر، والنمو الكبير يحتاج 6–12 شهراً من العمل المستمر، حسب المنافسة وقوة الموقع.
