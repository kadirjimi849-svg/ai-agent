# Narto Drama: الطيار الآلي للفيديوهات القصيرة

لوحة تحكم في المتصفح تربط **يوتيوب شورتس، فيسبوك ريلز، إنستغرام ريلز، تيك توك**.
بعد التشغيل يعمل كل شيء وحده: **كل 8 ساعات** يأخذ مسلسلاً من مجلد `D:\narto-drama`، ويستخرج أقوى لحظة فيه، ويصنع منها **فيديو عمودياً مدته 30 ثانية** يبدأ بـ hook قوي، ثم ينشره على كل الحسابات المربوطة.

```
D:\narto-drama\
   (مدبلج) أسطورة قرية السنام\   الحلقة 1.mp4, الحلقة 2.mp4 ...
   (مدبلج) انتقام الصياد\         01.mp4, 02.mp4 ...
   ... (100 مسلسل)
```
كل مجلد = مسلسل. اسم المسلسل يُؤخذ من اسم المجلد (تُحذف كلمة «(مدبلج)»). الحلقات تُرتَّب من الرقم الموجود في اسم الملف.

## كيف يُصنع كل فيديو (30 ثانية)

```
[2 ثانية: لقطة خاطفة من أقوى لحظة + زووم + نص الـ hook]  → ومضة بيضاء
[25 ثانية تنتهي بالضبط عند بداية اللحظة الصادمة = تشويق]
[3 ثوانٍ: بطاقة نهاية «ماذا سيحدث بعد ذلك؟» + اسم المسلسل]
```
- **أقوى لحظة** تُكتشف بدون تكلفة: قفزات الصوت (صراخ، صفعة، موسيقى صادمة) وكثافة تغيّر اللقطات.
- **الـ hook** يُختار حسب نوع المسلسل (انتقام، أسطورة/أكشن، ملياردير، هوية سرية...)، ولا يتكرر نفس النص في آخر 20 فيديو. مع مفتاح Anthropic يكتب Claude عبارات hook خاصة بكل مسلسل انطلاقاً من عنوانه.
- 1080×1920، شريط تقدم أحمر، اسم المسلسل ورقم الحلقة، صوت موحّد ‎-14 LUFS، وعربية سليمة.
- **التناوب:** لا يعيد نفس المسلسل مرتين متتاليتين، ويأخذ 3 لحظات من كل حلقة ثم ينتقل للحلقة التالية.
- **التعلّم:** كل 6 ساعات يسحب المشاهدات والإعجابات، ويعطي المسلسلات وأساليب الـ hook الرابحة فرصاً أكثر.

## التشغيل على ويندوز (مرة واحدة)

1. فك الضغط في مجلد اسمه إنجليزي، مثلاً `C:\narto-drama-bot`.
2. انقر مرتين على **`setup_windows.bat`**، فيثبّت Python و FFmpeg والمكتبات. إذا طلب منك إغلاق النافذة، أغلقها وشغّله مرة ثانية.
3. انقر مرتين على **`start_dashboard.bat`**، فتُفتح اللوحة في المتصفح على `http://localhost:8080`.
4. في اللوحة:
   - **المسلسلات:** تأكد أن المسار `D:\narto-drama` ثم اضغط «فحص المجلد».
   - **الإعدادات:** أدخل مفاتيح تطبيقات المنصات (الشرح أدناه).
   - **الحسابات:** اضغط «ربط» لكل منصة وسجّل الدخول.
   - **لوحة التحكم:** جرّب «اصنع فقط (بدون نشر)» وشاهد الفيديو، ثم فعّل **الطيار الآلي**.

**ليعمل 24 ساعة:**
- من إعدادات الطاقة اجعل الحاسوب لا ينام (Sleep = Never).
- للتشغيل مع ويندوز: `Win + R` ← اكتب `shell:startup` ← ضع فيه اختصاراً لـ `start_dashboard.bat`.
- إذا أُطفئ الحاسوب وفات موعد، ينشر البوت فور عودته ثم يكمل كل 8 ساعات.

## الحصول على مفاتيح المنصات

الشرح مفصّل داخل اللوحة (صفحة الحسابات ← «كيف أحصل على المفاتيح؟»). باختصار:

| المنصة | ماذا تنشئ | رابط الرجوع (Redirect) |
|---|---|---|
| يوتيوب | Google Cloud ← تفعيل YouTube Data API v3 ← OAuth client من نوع **Desktop app**. انشر شاشة الموافقة (Publish app) وإلا ينتهي الربط بعد 7 أيام | لا يحتاج إعداداً مع Desktop app |
| فيسبوك + إنستغرام | Meta for Developers ← تطبيق Business ← Facebook Login for Business | `http://localhost:8080/oauth/facebook` |
| تيك توك | TikTok for Developers ← Login Kit + Content Posting API (Direct Post) | `http://localhost:8080/oauth/tiktok` |

- **إنستغرام** يُربط من زر فيسبوك: يجب أن يكون الحساب احترافياً ومرتبطاً بصفحة فيسبوك. الفيديو يُرفع مباشرة من حاسوبك، فلا تحتاج سيرفراً.
- **تيك توك** قبل مراجعة تطبيقك ينشر الفيديوهات «خاصة» فقط. قدّم طلب المراجعة مبكراً.
- **يوتيوب** قبل تدقيق مشروعك قد تُرفع الفيديوهات «خاصة». اطلب التدقيق: https://support.google.com/youtube/contact/yt_api_form
- التوكنات تُحفظ فقط على حاسوبك في `data\bot.sqlite3`. لا تشارك هذا الملف.

## أوامر إضافية (اختيارية)

```
bot web                 لوحة التحكم + الطيار الآلي
bot autopilot --once    صنع ونشر فيديو واحد الآن من سطر الأوامر
bot library D:\narto-drama   فحص المجلد
bot stats / bot report  إحصائيات وما الذي يربح
bot preview FILE.mp4    تجربة المونتاج على أي ملف
```

## نصائح

1. **حقوق النشر:** انشر فقط المسلسلات التي تملك حق عرضها. بلاغات حقوق النشر المتكررة قد تُغلق الحساب.
2. **ابدأ بالوضع التجريبي:** شاهد 5 فيديوهات على هاتفك قبل النشر الحقيقي.
3. **حسابات تيك توك الجديدة:** انشر يدوياً وتفاعل أسبوعاً قبل تسليم الحساب للبوت.
4. **راقب صفحة المسلسلات:** ارفع أولوية المسلسل الذي يجلب مشاهدات، وأوقف الذي لا يجلب.
